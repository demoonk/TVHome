# TVHome 2.0.5

TVHome 2.0.5 устанавливается поверх 2.0.4 с сохранением данных. Идентификатор приложения `ru.pda.tvhome` и исходный ключ подписи сохранены.

- Нажатие на карточку в поиске открывает тот адрес, который приложение объявило само. Правила собраны в `SearchCardRules` и проверены на ТВ в гостиной (192.168.1.7) 2026-11-09 командами `content query` и `cmd package query-activities`:
  - NUM — строка несёт id и тип, работает app-link `themoviedb.org` (было единственным работающим случаем);
  - РешалаТВ — строка несёт собственный deeplink `reshala://open?screen=card:tmdb://movie/<id>`, провайдер `reshala.tv.app.poisk` отвечает только на `/search_suggest_query` без `/search`; ранее приложение исключалось из чтения результатов, поэтому карточек не было;
  - SmartTube — открывается только строка, у которой в `suggest_intent_data_id` есть настоящий видео-идентификатор. Реальные строки его не несут, поэтому ничего не выдумывается;
  - Кинопоиск и VK Видео — карточки берутся из веб-выдачи на хостах, которые приложения зарегистрили в своих intent-filter (`hd.kinopoisk.ru/film/<id>`, `vk.com/video-…`). Провайдер Кинопоиска отвечает `Unknown uri` на стандартном suggest-пути, провайдер VK требует `GLOBAL_SEARCH`, провайдер Vimu не экспортирован, КИОН отвечает пустой выдачей — карточек из провайдера там нет.
- Строка без проверенного целевого адреса уходит на exported search активность приложения, а её идентификатор передаётся через `SearchManager.EXTRA_DATA_KEY`, иначе приложение вообще не получает id строки.
- Boosty добавлен в проверенные поисковые входы: `https://vkplay.live/search?query=` резолвится в `live.boosty.tv.main.MainTvActivity`. Кнопка «Искать в …» по-прежнему обещает поиск только там, где вход или exported активность действительно проверены.
- Добавлены тесты на то, что любой путь в поиске ведёт к проверенному механизму: `SearchCardRulesTest` (JVM), `tests/test_search_card_rules.py` (harness без android.jar, сверяет правила и источник клика) и `tools/Verify-SearchLaunch.ps1` (проверка на самом ТВ: провайдер отвечает по правилу, каждый вход резолвится внутри приложения, поисковые активности экспортированы). Поведение интерфейса — открывается ли карточка, а не только резолвится интент — требует проверки на ТВ; в этой сессии приложения не выходили на передний план из adb.

Проверки: 266 JVM-тестов лаунчера (включая 6 новых), 43 теста установщиков. На ТВ в гостиной (Android 14, прошивка Ventura G4FFDVB95CQ) прогон `tools/Verify-SearchLaunch.ps1` — ALL PASS.

Для установки скачайте **TVHome-2.0.5.apk**. `update.json` используется встроенной проверкой обновлений.
