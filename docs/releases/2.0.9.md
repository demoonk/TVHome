# TVHome 2.0.9

TVHome 2.0.9 устанавливается поверх 2.0.8 с сохранением данных. Идентификатор приложения `ru.pda.tvhome` и ключ подписи сохранены, поэтому настройки лаунчера, выбранный помощник и режим загрузки моста не сбрасываются.

Проверено на ТВ в гостиной (192.168.1.7:5555) 2026-11-13.

## Что нового

- Сон лаунчера — это реальное выключение экрана, а не затемняющий оверлей. `SleepTimer.fireNow()` идёт по цепочке `DevicePolicyManager.lockNow()` → скрытый `PowerManager.goToSleep()` → `GLOBAL_ACTION_LOCK_SCREEN`; чёрный оверлей как fallback убран. После нажатия «выключи ТВ» экран действительно гаснет.
- В настройках «Система» раздел больше не открывает системные настройки Android по клику: теперь он раскрывает собственные строки TVHome, включая «Загрузка моста» и «Запросить загрузку сейчас». Без этого до строк моста было не добраться.

## Загрузка моста без диалога ключа

- Ключ помощника можно заранее внести в список доверенных ключей adbd через `IAdbManager.allowDebugging(true, key)`:

  ```sh
  service call adb 1 i32 1 s16 "<ключ помощника>"
  ```

  У shell на этой прошивке есть `MANAGE_DEBUGGING`, поэтому root не нужен. После этого помощник авторизуется без диалога, и мост поднимается сам после перезагрузки.
- Срок жизни ADB-ключей отключён: `settings put global adb_allowed_connection_time 0`. По умолчанию Android снимает «Всегда разрешать» через 7 дней без подключения; ноль означает «не истекает».

## Проверки

320 JVM-тестов лаунчера, 24 теста помощника, `lintRelease` — без отказов. После перезагрузки гостиной: помощник авторизовался по ключу из allow-list, `pqtv-bridge` поднялся сам, голосовой поиск работает (`assistant` = Katniss, `voice_interaction_service` = `LauncherAssistantService`).

## Известное поведение на этой прошивке

`getevent` находит пульт `TVC0GWBT Consumer Control` только когда он подключён по Bluetooth. Если пульт отключился или пропал (`mTargetDevice: null`), guard пишет `no remote` и продолжает искать; как только пульт вернётся, мост стартует сам без вмешательства. Это не ошибка моста.

Для установки используйте **TVHome-2.0.9.apk**.
