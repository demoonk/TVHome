# TVHome 2.1.2

Промежуточная сборка (`versionCode` 146) — диагностика голосового поиска на ТВ гостиной.
Настройки микрофона в этой сборке были убраны, в 2.1.3 возвращены.

## Что измерено

- кнопка микрофона пульта корректно запускает `ru.pda.tvhome.VoiceLaunchActivity` даже при замороженном
  Katniss — проверено `am start -a android.intent.action.ASSIST` и живым нажатием пульта;
- собственный захват звука лаунчером (`AudioRecord` + трубка в `EXTRA_AUDIO_SOURCE`) всегда давал плоский
  фон около 0,039 и `ERROR_NO_MATCH` после 10 с при 318 720 записанных байтах;
- `dumpsys media.audio_policy`: вход «Remote Submix In» (Port 9) заявлен, но не приписан ни к одному
  input mix port —audio-потока пульта приложение слышать не может;
- тот же разговор через собственную сессию движка распознавался сразу: `results 1 after 2255 ms`;
- распознаватель на устройстве один — `com.google.android.tts/GoogleTTSRecognitionService`;
- заморозка `com.google.android.gms` распознаванию речи не мешает: тесты кнопки прошли при
  `enabled=3`.
