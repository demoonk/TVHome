# TVHome 2.2.2

`versionCode` 159, `versionName` 2.2.2. Исправлена запись CPU в oверлейных часах.

## Что исправлено

В `assistant-package-guard.sh` был неправильный вызов Android helper:

```sh
cmd cmd settings put secure "$stats_key" "$busy" >/dev/null 2>&1
```

Android не понимает `cmd cmd settings ...`, поэтому setting `ru_pda_tvhome_cpu` не создавался.

Исправлено на:

```sh
cmd settings put secure "$stats_key" "$busy" >/dev/null 2>&1
```

Теперь при работе guard записывает текущий процент загрузки процессора:

```text
ru_pda_tvhome_cpu
```

И оверлейные часы могут показывать CPU без прямого доступа приложения к `/proc/stat`.

## Проверка после установки

```powershell
adb -s <IP>:5555 shell "settings get secure ru_pda_tvhome_cpu"
```

Должно быть число, например:

```text
43
```
