# TVHome 2.1.0

TVHome 2.1.0 устанавливается поверх 2.0.9 и более ранних версий с сохранением данных. Идентификатор приложения `ru.pda.tvhome` и ключ подписи не менялись, поэтому настройки лаунчера, выбранный помощник и режим загрузки моста остаются на месте.

## Что нового

- **Сон действительно выключает экран.** Раньше лаунчер показывал чёрную заглушку. Теперь `SleepTimer.fireNow()` идёт по цепочке `DevicePolicyManager.lockNow()` → скрытый `PowerManager.goToSleep()` → `GLOBAL_ACTION_LOCK_SCREEN`, а затемняющий оверлей удалён.
- **Настройки → «Система» открывают строки TVHome.** Раньше это место открывало системные настройки Android, и до строки «Загрузка моста» было не добраться. Теперь раздел раскрывает собственные строки, включая «Загрузка моста» и «Запросить загрузку сейчас».
- **Мост можно загружать без диалога ключа.** Ключ помощника вносится в доверенные ключи adbd один раз:

  ```sh
  service call adb 1 i32 1 s16 "<ключ помощника>"
  ```

  У shell на прошивке гостиной есть `MANAGE_DEBUGGING`, поэтому root не нужен. После этого помощник авторизуется молча и никогда не показывает «Разрешить отладку?».
- **Отключено истечение ADB-ключей.** По умолчанию Android снимает «Всегда разрешать» через 7 дней без подключения. Установка `settings put global adb_allowed_connection_time 0` возвращает ключам бессрочный статус.
- **`install.ps1` сохранён с UTF-8 BOM.** Windows PowerShell 5.1 без BOM показывал русский текст в последних строках установщика как кракозябры.

## Правка установщика после выпуска (2026-11-13)

`Setup-TVHome.ps1` в выпуске заменён: добавлены тесты, и 83 теста установщиков проходят без отказов.

- Виджет погоды и помощник моста больше не останавливают установку: `INSTALL_FAILED_UPDATE_INCOMPATIBLE` (другая подпись APK) — предупреждение с указанием команды для осознанной переустановки.
- Появился ключ `-ReinstallAddOns`: удаляет пакет помощника или виджета и ставит APK из выпуска.
- Контрольная сумма берётся также из сохранённого `SHA256SUMS.txt` более раннего выпуска, если текущий выпуск файл не перечисляет. Сам сохранённый `SHA256SUMS.txt` проверяется по digest GitHub, поэтому исправленный выпуск подтягивается автоматически и старая кэш-копия не удерживает установщик на прежних суммах.
- Скрипт моста (`assistant-package-guard.sh`) внутри установщика синхронизирован с `tools/assistant-package-guard.sh`: обработка запроса `launcher` теперь сохраняет Katniss включённым для физической кнопки микрофона пульта.
- В файлы выпуска добавлены `TVHome-weather.apk`, `TVHome-remote-2.1.0.dex`, `install.ps1` и `install.sh`, а `SHA256SUMS.txt` теперь перечисляет все файлы выпуска. DEX моста не менялся с 2.0.4 — опубликован тот же файл под именем выпуска.

## Файлы выпуска

- `TVHome-2.1.0.apk` — лаунчер, `versionCode` 144;
- `bridge-helper-1.7.apk` — помощник моста, `versionCode` 8;
- `Setup-TVHome.ps1` — установщик с UTF-8 BOM;
- `update.json` — данные для встроенной проверки обновлений.

В этом выпуске нет `TVHome-weather.apk`, DEX моста и скриптов `install.ps1`/`install.sh`. Установщик берёт их из кэша и проверяет по сохранённым `SHA256SUMS.txt` более раннего выпуска; если файла в кэше нет, виджет погоды и мост не устанавливаются. Это не ошибка лаунчера: Home, разрешения и голос настроены.

**Про подпись помощника моста.** Первое опубликование `bridge-helper-1.7.apk` в 2.1.0 было собрано с локальным `~/.android/debug.keystore` (сертификат `07d8c58d…`), тогда как на телевизорах стоит помощник, подписанный ключом выпуска `067cc924…`. Android не позволяет заменить уже установленный пакет APK с другой подписью и отвечает `INSTALL_FAILED_UPDATE_INCOMPATIBLE`. 2026-11-13 файл выпуска заменён воспроизводимой сборкой того же кода с ключом выпуска: `bridge-helper-1.7.apk` (16 760 байт) → SHA-256 `c10a734734cc4361d31aef6ad11b4605ec11d2e71df6af7b6e608d81895d1a2d`, тот же файл, что установлен на обоих ТВ. Обновление проходит через `install -r` без удаления пакета, ключ помощника не сбрасывается. В следующих выпусках все APK подписываются одним ключом (`-PtvhomeKeystore=…`), а изменившийся помощник получает новый `versionCode`.
