# TVHome 2.1.0

TVHome 2.1.0 устанавливается поверх 2.0.9 и более ранних версий с сохранением данных. Идентификатор приложения `ru.pda.tvhome` и ключ подписи не менялись, поэтому настройки лаунчера, выбранный помощник и режим загрузки моста остаются на месте.

## Что нового

- **Сон действительно выключает экран.** Раньше лаунчер показывал чёрную заглушку. Теперь `SleepTimer.fireNow()` идёт по цепочке `DevicePolicyManager.lockNow()` → скрытый `PowerManager.goToSleep()` → `GLOBAL_ACTION_LOCK_SCREEN`, а затемняющий оверлей удалён.
- **Настройки → «Система» открывают строки TVHome.** Раньше это место открывало системные настройки Android, и до строки «Загрузка моста» было не добраться. Теперь раздел раскрывает собственные строки, включая «Загрузка моста» и «Запросить загрузку сейчас».
- **Мост можно загружать без диалога ключа.** Ключ помощника вносится в доверенные ключи adbd один раз:

  ```sh
  service call adb 1 i32 1 s16 "<ключ помощника>"
  ```

  У shell на прошивке гостиной есть `MANAGE_DEBUGGING`, поэтому root не нужен. После этого помощник авторизуется молча и никогда не показывает «Разрешить отладку?».
- **Отключено истечение ADB-ключей.** По умолчанию Android снимает «Всегда разрешать» через 7 дней без подключения. Установка `settings put global adb_allowed_connection_time 0` возвращает ключам бессрочный статус.
- **`install.ps1` сохранён с UTF-8 BOM.** Windows PowerShell 5.1 без BOM показывал русский текст в последних строках установщика как кракозябры.

## Проверки

- `testReleaseUnitTest` лаунчера и помощника — 0 отказов;
- `lintRelease` — 0 ошибок;
- `assembleRelease` — сборка успешна;
- 81 тест установщиков `python -m unittest discover -s tests` — 0 отказов;
- сквозная проверка документированной команды против подставного ADB `python tests/smoke_installer_docs.py` — скрипт подключается, ставит APK через `install -r`, выдаёт и проверяет разрешения часов, запускает главный экран. Обе документированные формы адреса (`IP:PORT` и голый `IP`) принимаются.

Тест с перезагрузкой на реальном ТВ в этой сессии не выполнялся: его делает владелец обновлением с ТВ.
