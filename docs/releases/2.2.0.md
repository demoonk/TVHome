# TVHome 2.2.0

`versionCode` 157, `versionName` 2.2.0. Оверлейные часы: показатели CPU и свободной памяти.

## Что добавлено

- В настройках оверлейных часов появились отдельные переключатели:
  - «Показывать загрузку процессора»;
  - «Показывать свободную память».
- Когда переключатели включены, перед часами в оверлейной строке показываются:
  - иконка CPU и загрузка процессора в процентах;
  - иконка памяти и свободная память в МБ.
- Размер текста показателей, шрифт и иконки подстраиваются под фактическую высоту строки часов.
- Одинаковый промежуток между CPU и памятью, а также между памятью и часами.
- При позиционировании часов показатели временно скрываются, чтобы стрелки влево/вправо двигали часы без смещения от показателей.

## Значения

- Загрузка процессора берётся из безопасного значения `ru_pda_tvhome_cpu`, которое обновляет helper-скрипт:
  - прямой доступ к `/proc/stat` из приложения Android заблокирован SELinux;
  - helper пишет значение каждые 5 секунд.
- Свободная память берётся из `ActivityManager.MemoryInfo` и показывается в мегабайтах.
