# TVHome 2.2.1

`versionCode` 158, `versionName` 2.2.1. Разморозка HDMI-сервисов при старте помощника.

## Что исправлено

- При старте `assistant-package-guard.sh` на этих моделях ТВ проверяет системные сервисы входов/HDMI.
- Если они заморожены для пользователя 0, они размораживаются автоматически.
- Сервисы:
  - `com.android.tv.settings` — системные настройки ТВ, экран «Каналы и входы»;
  - `com.mediatek.tvinput` — MediaTek-сервис TV InputManager, HDMI-входы `HW5`, `HW6`, `HW7`;
  - `com.mediatek.tv.service` — системная служба ТВ.

## Поведение

- Если сервис уже включён, ничего не меняется.
- Если сервис отсутствует, скрипт его не трогает.
- Факт разморозки записывается в trace-файл помощника:
  ```text
  /data/local/tmp/assistant-package-guard.trace
  ```

## Проверка

```powershell
adb -s 192.168.1.3:5555 shell "cat /data/local/tmp/assistant-package-guard.trace"
adb -s 192.168.1.3:5555 shell "dumpsys package com.mediatek.tvinput | grep -E 'User 0:|lastDisabled'"
adb -s 192.168.1.3:5555 shell "dumpsys tv_input | grep HDMIInputService"
```
