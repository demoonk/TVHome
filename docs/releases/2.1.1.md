# TVHome 2.1.1

Обновление поверх 2.1.0 без потери настроек: `versionCode` 145, `versionName` 2.1.1, идентификатор и ключ подписи не меняются.

## Что изменилось

### Выбор помощника теперь решает, кто заморожен
- Строка «Голосовой помощник» в настройках лаунчера выбирает один из двух вариантов:
  - **Встроенный в лаунчер** — `assistant` = `ru.pda.tvhome/.VoiceLaunchActivity`, Katniss (`com.google.android.katniss`) замораживается;
  - **Системный (Google)** — `assistant` = `com.google.android.katniss/.search.serviceapi.KatnissVoiceInteractionService`, Katniss размораживается.
- Помощник моста (`assistant-package-guard.sh`) повторяет это при каждой загрузке: если в `secure/assistant` записан лаунчер, Katniss замораживается снова (в трассе появляется строка `katniss frozen for the launcher assistant`); режим `launcher` и режим `system` в guard-скрипте делают то же самое явно.
- Физическая кнопка микрофона на пульте работает в обоих случаях: её обработчик — `com.google.android.tv.remote.service`, он отправляет `ACTION_ASSIST` тому, что записано в `assistant`. Проверено на ТВ гостиной: `am start -a android.intent.action.ASSIST` открывает `ru.pda.tvhome.VoiceLaunchActivity` при замороженном Katniss.

### Список заморозки расширен
Добавлены строки:
- `com.android.cts.ctsshim` и `com.android.cts.priv.ctsshim` — тестовые пакеты CTS из apex-модуля, для работы ТВ не нужны;
- `com.android.tv.feedbackconsent` — экран согласия на отправку отзывов (сам сбор отзывов уже заморожен).

Список защищённых пакетов (их нельзя заморозить ни из лаунчера, ни из guard-скрипта) дополнен блоком ядра Android: `com.google.android.ext.services`, `com.google.android.ext.shared`, `com.google.android.modulemetadata`, `com.google.android.permissioncontroller`, `com.google.android.safetycenter.resources`.

### Голосовой поиск: надписи больше не наезжают на спиннер
- В строке статуса раздела («Поиск…») у текста появился собственный отступ, раньше кольцо спиннера касалось надписи.
- Пока постер карточки не загрузился, её заголовок был центрирован и попадал под кольцо спиннера. Теперь текст прижат к нижнему краю обложки, максимум две строки.
