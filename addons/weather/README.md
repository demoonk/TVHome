# Weather

Виджет погоды для TVHome: один город, экран целиком — сейчас (температура, ощущается как, состояние), индекс
качества воздуха и следующие три дня. Для TVHome это отдельное приложение с read-only provider
(`WeatherProvider`), из которого лаунчер читает последние значения в шапке, и `RefreshReceiver` — одна свежая
загрузка по запросу лаунчера, без фонового сервиса.

Город выбирается в самом приложении (клавиатурой пульта или голосом) и сохраняется; «Change city» внизу меняет
его. Данные — [Open-Meteo](https://open-meteo.com/) без аккаунта и ключа: погода из модели ICON, качество
воздуха из CAMS. Осадки около нуля показываются как снег по температуре по влажному термометру, потому что
модели называют снег «light rain» при +1 °C.

Градусы Цельсия, слова английские; названия дней следуют языку телевизора.

## Права

| Permission | Why |
|---|---|
| `INTERNET` | Open-Meteo: поиск места, погода и качество воздуха. |

Ничего больше. Отправляется имя города, который вы вводите, и его координаты. Нет аккаунта, телеметрии, рекламы,
фонового сервиса и права на геолокацию. Город хранится в собственном хранилище приложения (резервные копии выключены).

## Сборка и установка

JDK 17 и Android SDK platform 34 с build-tools 34.0.0, как для лаунчера:

```bash
cd addons/weather && ./gradlew testReleaseUnitTest lintRelease assembleRelease
```

Release собирается с debug-ключом, потому что устанавливается по ADB, как лаунчер:

```bash
./gradlew assembleRelease -PtvhomeKeystore=C:/private/TVHome.keystore
```

Публикуется как `TVHome-weather.apk` в релизе TVHome; интерактивный установщик `Setup-TVHome.ps1` скачивает его
с проверкой SHA-256 и устанавливает, если ассет есть в релизе. Виджет нельзя замороживать: он читает свои
значения через provider.

Сборка APK не побайтово идентична (в подписи v3 есть метка времени), но содержимое воспроизводится из этих
исходников; SHA-256 в `SHA256SUMS.txt` соответствует опубликованному файлу.
